Computational neuroscience

How do circuits link related memories?

A bilateral CA3–CA1 spiking network to study memory formation and generalisation.

Peking University · Guozhang Chen’s group2026–present

The question

When a fear response transfers from one context to another, have the two memories become associated, or has the network lost the information that distinguishes them? I use a bilateral hippocampal model to ask how circuit structure and plasticity might produce these different outcomes.

Building a model when the connectome is incomplete

I built a CA3–CA1 spiking network with nearly 60,000 neurons and roughly 30 million synapses. Both hemispheres include excitatory, PV, and SST populations. The model combines constraints on cell-type firing properties, neuron numbers and positions, and axonal projections.

My main methodological contribution is a Bayesian connectivity framework using conditional relative-entropy reconstruction. It combines complementary anatomical sources to estimate connection probabilities conditioned on neuronal type and spatial position, while respecting available marginal constraints.

My contributions

  • Derived and implemented the connectivity reconstruction framework, including rescaling for a smaller, non-uniformly sampled network.
  • Identified missing inhibitory inputs introduced by independent Bernoulli sampling, and added a coverage correction for sampled neurons.
  • Calibrated excitation–inhibition dynamics with Optuna to establish a baseline for task experiments.
  • Developed the spiking-network model and the experimental framework for studying memory formation and generalisation.

Current result: context learning and pattern completion

Initial simulations show pattern-completion responses for two learned contexts: partial context cues recover the corresponding learned representation. This is an intermediate result toward the broader question of memory generalisation.

Ongoing work. The context–shock association mechanism, offline-stage hypotheses, and freezing-related readout are under development. They are proposed tests, rather than established explanations of behavioural generalisation.

What comes next

I am developing a four-stage protocol linking context learning, context–shock association, offline activity, and retrieval. Candidate mechanisms include BTSP-mediated hetero-association, EC3/SST modulation of plateau gating, and offline reactivation.

The key comparison will measure transfer of a shock-related representation alongside retained context identity, to distinguish memory association from a loss of context-specific information.
